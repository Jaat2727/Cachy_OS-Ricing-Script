# 🍚 cachyXhyprland-fried-rice

A premium Hyprland rice for CachyOS / Arch Linux — featuring elastic animations, dynamic wallpaper theming, a reactive AGS top bar, and a glassmorphism notification center.

https://github.com/user-attachments/assets/42859c7b-5c34-41d0-aebc-7b745d4ff733

## ⚡ One-Line Install

```bash
git clone https://github.com/Jaat2727/Cachy_OS-Ricing-Script.git
cd Cachy_OS-Ricing-Script
chmod +x install.sh && ./install.sh
```

The installer will:
- Install all required packages (via `pacman` + `yay`)
- Safely backup your existing `~/.config` to `~/.config-backup-<timestamp>`
- Deploy all rice configs via `rsync`
- Copy wallpapers to `~/Downloads/Wallpapers`
- Set up GTK 4.0 theme symlinks
- Make all scripts executable
- Tell you to reboot 🚀

## 🎨 Theming

Colors are auto-generated by **Matugen** from your current wallpaper. When you switch wallpapers (`Super + W`), the entire theme updates:
- AGS bar colors
- Fuzzel launcher colors
- SwayNC notification center
- Kitty terminal
- GTK 3.0 & 4.0 apps
- Hyprland borders

## 📦 Manual Install

If you prefer not to use the auto-installer:

```bash
# Install yay if needed
sudo pacman -S --needed base-devel git
git clone https://aur.archlinux.org/yay.git && cd yay && makepkg -si

# Install packages
sudo pacman -S hyprland kitty thunar btop brightnessctl playerctl wl-clipboard grim slurp jq rsync imagemagick
yay -S fuzzel swaynotificationcenter aylurs-gtk-shell matugen-bin swww hyprlock nwg-look adw-gtk3 wlogout rofi-wayland

# Copy configs
cp -r .config/* ~/.config/

# Copy wallpapers
cp -r Wallpapers ~/Downloads/

# Make scripts executable
chmod +x ~/.config/hypr/*.sh
chmod +x ~/.config/hypr/scripts/*.sh
chmod +x ~/.config/matugen/hooks/*.sh
chmod +x ~/.config/waybar/scripts/*.sh

# GTK 4.0 assets symlink
rm -f ~/.config/gtk-4.0/assets
ln -s /usr/share/themes/adw-gtk3-dark/gtk-4.0/assets ~/.config/gtk-4.0/assets
```

## 🔄 Rollback

To switch back to Waybar from AGS, edit `~/.config/hypr/hyprland.conf`:
```
exec-once = waybar    # instead of ags
```

To switch back to Rofi from Fuzzel:
```
$menu = rofi -show drun    # instead of fuzzel
```

## 🖥️ VM Users

The wallpaper script automatically detects VM environments (VirtualBox, VMware, QEMU, KVM, Hyper-V) and adds a 2-second delay before applying wallpapers to prevent `swww` GPU crashes. No configuration needed.
